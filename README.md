## 🎨 Key Features & Architecture Summary

1. **Light-Blue Command Center Theme:**
   - Canvas Base: `#F0F6FC`
   - Panels & Cards: `#FFFFFF` with `#D0DFEE` border
   - Primary Accent: `#2B7FFF` Signal Blue
   - Typography: `Inter` + `JetBrains Mono`

2. **3 Core Operational Views:**
   - **View 1 (Overview):** Railway Track Interlocking Diagram (circuits `BLK-101`, signals `S-12`/`S-14`, switches `P-4A`) + Triage Agent Queue.
   - **View 2 (Loco-Cab View):** Locomotive Forward Camera feed + Interactive 4-Agent Pipeline Canvas Animation (`[APPLY BRAKING FORMULA]`).
   - **View 3 (Platform Gateway View):** Platform Entrance CCTV (Pillar #1) + 5-Min Deterministic Hold & Dynamic ML Extension countdown timer.

3. **Deployment Modes & Auditor Logging:**
   - **Advisory Mode (Phase 1):** Dispatcher Review & Manual Approval (`[APPROVE ACTION]`).
   - **Autonomous Mode (Post-RDSO Cert):** Instant auto-execution.
   - **Explainable Decision Logs:** Auditor & Maintenance Engineer compliance filing workspace.
