# Vibe Kanban: Multi-Agent Sprint Tracker

## Purpose
Track active tasks across Backlog, In Progress, In Review, and Done.

## Integration
- Maps to tickets generated by `/wayfinder` and `planning-with-files`.
- Keeps execution transparent across multiple subagents.
