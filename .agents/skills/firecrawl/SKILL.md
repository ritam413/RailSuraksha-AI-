# Firecrawl Web Scraper & Crawler

Use this skill to extract clean documentation from complex JavaScript-rendered web pages.

## Directives
1. Use to crawl official specs, API references, or release docs.
2. Strip navbars, ads, tracking scripts, and cookie banners automatically.
3. Save structured markdown directly into `docs/` or pass to `/research`.
