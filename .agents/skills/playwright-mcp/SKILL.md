# Playwright MCP Automation

## Purpose
Automate headless browser testing, screen capture, and visual validation.

## Directives
1. Run automated cross-browser snapshots (desktop and mobile viewports).
2. Assert on DOM element states, form inputs, and interactive clicks.
3. Validate layout stability and visual contrast against `DESIGN.md`.
