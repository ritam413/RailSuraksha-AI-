# Awesome-Claude-Skills: Reusable Skill Catalog & Registry

## Mental Model
`awesome-claude-skills` indexes community and enterprise skills, providing reference implementations, specialized tool adapters, and domain-specific workflows for rapid adoption.

## Skill Categories & Recipes

1. **Testing & QA:**
   - Red-Green TDD engines, mutation testing runners, property-based fuzzers.
2. **Infrastructure & DevOps:**
   - Terraform linter, Docker Compose orchestrator, Kubernetes deployment auditor.
3. **Data & Analytics:**
   - SQL query optimizer, schema migration validator, pipeline profiler.
4. **Documentation & Knowledge:**
   - API doc generator, architectural decision record (ADR) formatter, changelog synthesizer.

## Discovery & Installation Workflow

1. **Search:** Query catalog by task category or domain need.
2. **Inspect:** Check SKILL.md frontmatter, tool dependencies, and permitted actions.
3. **Validate:** Test skill in an isolated subagent sandbox prior to global repository adoption.
